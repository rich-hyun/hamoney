# 하모니 (Harmony) 모바일 UI 프로토타입

하나금융그룹 시니어 모임금융 서비스 "하모니" 인터랙티브 목업입니다.

## 파일 구성
- `index.html` — 화면 구조 및 동작(JS 포함)
- `styles.css` — 전체 스타일

이미지(로고, 캐릭터, 배경)는 모두 base64로 파일 안에 포함되어 있어 별도 이미지 파일 없이도 바로 열립니다.

## 화면이 보이는 방식
- **실제 휴대폰**으로 열면: 화면 전체를 꽉 채우는 진짜 앱처럼 보입니다. 폰 자체 상태바(시계·배터리 등)를 그대로 쓰고, 가짜 테두리나 노치는 표시되지 않습니다.
- **데스크톱/노트북 브라우저**로 열면: 진한 초록 테두리 + 노치 + 9:41 상태바가 있는 폰 목업 카드 형태로 가운데 정렬되어 보입니다 (발표 자료·리뷰용으로 스크린샷 찍기 좋습니다).

두 모드는 화면 너비 640px를 기준으로 자동 전환되며, 별도 설정이 필요 없습니다.

## 화면 구조
- 하단 탭 5개(홈/모임/혜택/리포트/전체) — 탭을 누르면 즉시 전환, 나머지 탭은 완전히 숨겨집니다.
- 홈 화면은 인사말 + 모임 만들기 + 3개의 메뉴 카드로 구성 (스크롤 없이 한 화면에 표시)
- "이번 주 일정" / "추천 컬처존" 카드를 누르면 오른쪽에서 새 화면이 슬라이드로 들어오고,
  상단의 **‹ 뒤로** 버튼이나 실제 뒤로가기(브라우저/스마트폰 제스처)로 돌아갈 수 있습니다.
  우측 상단 홈 아이콘으로 바로 홈으로 이동할 수 있습니다.

## 실행 방법
`index.html`을 더블클릭해서 브라우저로 열면 됩니다. 별도 서버 없이도 정상 동작합니다.

GitHub Pages로 배포할 경우, 저장소 루트(또는 `docs/` 폴더)에 두 파일을 그대로 올리면 됩니다.
